# CIT Smart Scheduler 🎓

An intelligent academic scheduling platform for Chilika Institute of Technology (CIT).

The platform aims to automate semester timetable generation, examination scheduling, venue bookings, and disruption-based rescheduling while respecting academic constraints and institutional priorities.

## 🚀 Features

* Automated semester timetable generation
* Examination scheduling
* Spectra event venue booking management
* Conflict detection and resolution
* Disruption-aware timetable rescheduling
* AI-powered natural-language requests in English and Hinglish
* Role-based dashboards for administrators, coordinators, faculty, and club representatives

## 🛠️ Tech Stack

* **Frontend:** React + Vite
* **Backend:** Node.js + Express.js
* **Database:** PostgreSQL
* **Scheduling Engine:** Python + Google OR-Tools
* **Validation:** Official hackathon validator
